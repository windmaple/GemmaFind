Truly multimodal

One search box for every kind of file.

EmbeddingGemma 2 maps text, images, video and audio into a single 768-dimensional space. GemmaFind calibrates scores per modality, so a photo and a document can compete fairly for the top spot.

Private & fast

Nothing ever leaves your Mac.

The model runs locally through Google's LiteRT-LM on the Metal GPU. No accounts, no cloud, no telemetry. Your index lives in a single SQLite file you own.

How it works

From folders to answers in four steps.

Watch

Indexes ~/Documents, ~/Desktop and ~/Downloads (or any folder you choose) and keeps up with changes via FSEvents.

Understand

Splits text into sentence-aligned passages, samples video frames every 10 s and slices audio into 20 s clips.

Embed

EmbeddingGemma 2 turns every passage, photo, frame and clip into a 768-d vector, on your GPU.

Rank

Cosine similarity, calibrated per modality, fused with an FTS5 keyword boost so exact names still win.

Install

Build it in one command.

GemmaFind is a native Swift app. Clone it, run the build script, and open it. The model (485 MB) downloads on first launch.

# requires Xcode 16+ (or Command Line Tools)
$ git clone https://github.com/windmaple/GemmaFind
$ cd GemmaFind
$ ./build_app.sh
$ open GemmaFind.app
1
macOS 14 or later, Apple Silicon

Runs on the Metal GPU through LiteRT-LM, with a CPU fallback.

2
Allow folder access

macOS asks once for Documents, Desktop and Downloads. Change folders anytime in Settings.

3
Press ⌃Space

Indexing runs in the background — text first, so documents are searchable within moments.

Heads-up: macOS uses ⌃Space to switch input sources by default. If you type in more than one language, turn it off under System Settings → Keyboard → Keyboard Shortcuts → Input Sources. GemmaFind will remind you.

FAQ

Questions, answered.

Does anything get sent to the cloud?

No. The embedding model runs locally via LiteRT-LM, and the index is a SQLite file on your disk. The only network request is the one-time model download from Hugging Face.

What is EmbeddingGemma 2?

An open multimodal embedding model from Google DeepMind that maps text, images, video and audio into one 768-dimensional space. GemmaFind uses the 740M-parameter LiteRT-LM build, quantized for on-device use.

How much disk and memory does it use?

The model is 485 MB. The in-memory search index takes about 3 KB per passage — roughly 300 MB for 100,000 passages.

Which files does it index?

Text, Markdown and source code; PDF; Word, RTF, ODT and HTML; JPEG, PNG, HEIC and other images; MP4/MOV video (frames and soundtrack); and M4A, MP3, WAV and other audio. You can switch any type off and add exclusion patterns in Settings.

Is it free?

Yes — free and open source. Contributions and bug reports are welcome on GitHub.
